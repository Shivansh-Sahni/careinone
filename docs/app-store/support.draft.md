## Add a note or paste text

Choose **Add an update**, select the text input, and type or use the system paste control. Keep important line breaks. Add an event date only if you know when the information occurred, then save. Saving keeps the source; reviewing its proposed details makes accepted information part of My Care.

If a field or paste action fails, keep the text in a place you control, reopen the input, and retry. Report the failing field and whether the copied content was plain text, a photo, or a file. Do not delete existing records to troubleshoot a paste problem.

## An import did not finish

Use a supported PDF, image, plain-text, or FHIR JSON file. Check that the file is available locally and is not locked. Select the file again if a cloud file provider did not finish downloading it. A saved original can remain available even when OCR or transcription is incomplete; compare extracted text with that original and add an editable recap if necessary.

## Analysis failed

Open the saved source in **Sources**. Retry when the service is available, use local analysis, or enter a structured detail manually. Review supporting quotations before accepting important information.

Cloud analysis is optional and depends on an enabled connection, permission for the displayed providers, and service availability. A changed provider requires renewed permission in **Settings → Set up or test cloud connection**. Do not enter an OpenAI API key into the app's gateway-token field.

## A detail is missing from My Care

Check whether the source still needs review. A proposed detail does not become reviewed care until you accept it. Conflicting reports can remain separate; ask your care team which instruction applies rather than assuming the app resolved the difference.

## Reminders and calendar events

Enable local reminders in Settings and allow notifications when prompted. Confirm explicit dates; the app does not invent dates for undated tasks. If you denied system permission, review CareInOne's permissions in iOS Settings.

Adding a reviewed appointment to Calendar is a separate action. Confirm the date and details before adding it. A repeated tap or relaunch does not automatically add another copy; explicitly confirm **Add another calendar copy** if one is needed. An event already added remains in your calendar unless you remove it there. Edits in CareInOne do not update that copy, so change an exported appointment's date/details in Calendar. Fictional practice does not add events to your personal calendar.

## Recordings and transcription

Ask everyone present before recording a visit. Recording pauses when you leave the app. On-device transcription may be unavailable for a language or device. You can keep locally captured audio for recovery and type a recap. Review the transcript against what was actually said before accepting consequential details.

## Move or protect your information

Use **Settings → Encrypted backup & restore** to make a passphrase-protected backup. Save the file somewhere you control and keep the passphrase separately. Check the app's size limits before making a large backup. The app does not automatically synchronize records through iCloud.

Restore previews a backup and replaces the active local records after confirmation; it does not silently merge two histories. Back up existing records before replacing them.

Use **Care Brief → Choose what to include** to share selected context as text or PDF. Exported files and shared copies remain in their chosen destinations.

## Delete information

Delete a source from its detail screen, delete retained audio separately, or use **Settings → Delete all local data**. Deleting local information does not recall material already exported, shared, or processed by a cloud provider. Consult the privacy policy for cloud retention and privacy-contact requests.

## Try the fictional example

On first launch choose **Explore the fictional demo**, or open it from Settings. A banner identifies its separate practice workspace. Use **Return to my care** to leave it, or **Settings → Reset fictional demo** to reset only practice changes. Demo sources do not merge into personal care. Use fictional practice materials to learn imports and review.
